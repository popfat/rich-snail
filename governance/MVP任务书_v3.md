## 1. 一句话任务定义

> **每个交易日 14:50（paperwalk 模式），基于已有特色指标和必要行情输入，输出大盘状态观察、指标一致与冲突、风险提示、证据缺口和暂不能下的结论，并记录当次模拟决策；同时建设按需运行的历史回测模式，用时间切分数据验证指标与假设。**

## 2. 使用者与双模式

| 项 | 内容 |
|---|---|
| 使用者 | 项目所有者本人（个人研究与决策支持，非对外产品） |
| 主责分支 | B0 定义契约；B1/B2 提供输入；B3/B5/B7 实现闭环；B6 评测与回测 |

### 模式 A：paperwalk（每日固定推进）

| 项 | 内容 |
|---|---|
| 时点 | **每个交易日 14:50**（所有者 Q4 决策；盘中估计沿用现有 `intraday_temp_live.py` 通道，权威值仍以收盘后日更管线为准） |
| 动作 | 生成当次报告 → 人工记录模拟决策 → 保存 DecisionLog 与 PaperTradeRecord → 事后结果**追加**关联 |
| 模拟标的与账本 | **沪深300ETF（510300）单一标的**；行动空间 `enter/exit/hold/observe/no_trade`；二值仓位（满仓进出）；T 日 14:50 决策按 T 日收盘价模拟成交；成本常数化并版本化；产出日频模拟净值（NAV）序列（口径详见《核心数据契约》§2.7a，所有者 R2 决策） |
| 核心价值 | **从实践中积累**：每次决策的当时输入、判断、结果沉淀为案例与交割记录，进入知识库候选，为后续决策与 RSI 提供真实素材（所有者 Q2 决策）；NAV 用于评估决策质量 |
| 性质 | 模拟观察，**不是实盘授权**，不产生真实交易指令 |

### 模式 B：backtest（按需运行，无固定时点）

| 项 | 内容 |
|---|---|
| 时点 | 按需触发，不设固定调度（所有者 Q4 决策） |
| 数据切分 | 历史数据按时间顺序分为**训练集 / 验证集 / 评测集**（切分点在每个实验卡中显式声明并版本化；**不设全局默认切分**（所有者 R3 决策）；评测集在实验设计冻结前不得用于调参） |
| 动作 | 围绕明确假设运行 as_of 严格回放 → 与基准对照（含沪深300ETF 买入持有基准）→ 产出 Experiment（含负面结果与失败切片） |
| 账本口径 | **复用 paperwalk 同一账本**（同一标的、成本与成交假设），保证历史与前向可比 |
| 核心价值 | 检验指标与候选命题是否有增量，为知识晋级/降级提供证据 |

两模式关系：paperwalk 产生**前向真实素材**（防过拟合的最终裁判），backtest 提供**历史证据**；backtest 结论不得用 paperwalk 期间之后的信息污染 paperwalk 当时输入。

## 4. 输出（AnalysisReport 最小结构）

报告必须包含以下分区（字段细目见《核心数据契约》）：

0. **模式标识**：`mode: paperwalk | backtest`；backtest 报告另标实验 ID 与数据集切分引用；
1. **事实区**：当日行情与指标读数（数值只能来自确定性计算，标注数据快照 ID 与指标版本；14:50 盘中值标注"估计"口径）；
2. **状态观察区**：画像状态、信号状态、行业资金状态及其一致与冲突（含冲突双方各自来源）；
3. **解释与假设区**：外部观点、个人经验、LLM 假设**分栏**，各自标注证据状态；
4. **风险提示区**：失效条件、不交易条件、当前证据不支持的动作；
5. **证据缺口区**：本次报告缺少什么证据、哪些卡片类型为空；
6. **弃权区**：暂不能下的结论及原因；满足弃权条件时主体结论必须为"证据不足"；
7. **模拟决策区（paperwalk 专属）**：当次模拟行动/不行动、依据引用；该区分快照不可改写，事后结果另行追加；
8. **版本与引用区**：数据快照 ID、指标版本、知识版本、检索 as_of、模型与提示词版本。

## 5. 反馈闭环（paperwalk → 知识库 → RSI）

```text
14:50 报告 + 模拟决策
   → DecisionLog（当时快照，不可改写）
   → PaperTradeRecord 模拟交割记录（行动、依据、版本）
   → 事后结果追加关联（不回改当时字段）
   → 定期沉淀为候选案例卡/行为素材（B2，pending_review）
   → 重复模式进入假设卡 → backtest 模式验证（Experiment）
   → 晋级/降级建议 → 人工审核
   → RSI（S3 后 L0 只读缺口报告 → L1 候选研究；自动晋级始终禁止）
```

## 6. 弃权条件（满足任一条，报告必须返回"证据不足"）

- 当日关键数据快照缺失或质量状态为失败/存疑（如 margin 三所未齐、ETF 份额 T+1 未发布、盘中快照通道失败）；
- 核心指标无法按固定版本复现（同快照重算结果不一致）；
- 检索证据包为空，或仅有 `pending_validation` 知识而无任何 `observing`/`active` 知识支撑关键判断；
- 指标之间出现契约内未定义处理方式的方向性冲突；
- 数据可见时间无法确认（存在未来函数风险）；backtest 模式下切分或 as_of 校验失败；
- 模型/数据源调用失败——输出降级报告并显式标记，**不得伪造完整报告**。

## 7. 首期不做（非目标）

- 不输出真实买卖点、实盘仓位建议或收益承诺；不接入自动交易；paperwalk 为模拟性质；
- backtest 结果≠实盘授权，只作知识证据；
- **不做交易 App 级簿记**：不做多标的组合、部分仓位、均价/浮盈/逐笔交割簿、盘中撮合、杠杆与衍生品（所有者 R2 决策：利润可算即可，深度到此为止）；
- **不重复实现指标**：只登记/引用既有项目的计算产物与公式版本（所有者 D8 决策）；运行中发现的指标灵感只提交提议报告所有者，不自行实现；
- 不做全量资料向量化；不要求知识卡片类型齐备（无材料支持的类型保持为空）；
- 不新建独立复杂 dashboard：8089 雷达新增 rich-snail 卡片页 + 详情页（按 `docs/signal_detail_page_spec.md` 规范，所有者 Q5 决策）；
- 不接入新闻管道（B4 等待真实任务缺口）；
- RSI 在 MVP 内只建设其**数据前提**（日志、交割、评测材料），L0 只读报告待 G3 后开放，不做自动改进；
- 不以短期盈利（含模拟 NAV）作为首期评价。

## 四、风险与失效条件
- 失效条件：{...}；不交易条件：{...}

## 五、证据缺口
- 缺少：{案例卡/行为卡…}；影响：{...}

## 七、模拟决策区（paperwalk）

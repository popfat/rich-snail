# 评价方案（v2 · 四层指标体系）

> 工作包：WP-B06-01 ｜ 依据：Roadmap §1.3、§10；知识库文档 §16；2026-11-22 所有者 Q2 决策（MVP 双模式）
> 日期：2026-11-22 ｜ 状态：draft，待 G0 人工审核（v2）
> v2 变更：补充 paperwalk 反馈闭环累积指标与 backtest 训练/验证/评测切分合规指标。
> 原则：**四层指标不互相替代**；投资效果层不作为首期（S0—S3）验收条件；被评价对象不得自评通过（评测由 B6 独立执行，晋级需人工审核）。

## 1. 四层指标总表

### L1 工程可靠性（S1 起可测）

| 指标 | 口径 | 首期通过线 |
|---|---|---|
| 显式失败率 | 失败运行中有显式 `failed` 状态记录的比例（目标：无静默失败） | 100% 显式 |
| 可复现性 | 同一 MarketSnapshot + 同一 formula_version 重算，结果一致的次数/总次数 | 100% |
| 可追溯率 | 报告关键数值能回溯到快照 ID 与指标版本的比例 | 100% |
| 重跑安全性 | 重跑不覆盖历史运行记录（抽查） | 不覆盖 |
| 版本可回滚 | 正式版本存在可回滚引用 | 全部具备 |
| 成本与延迟可观察 | 每次运行记录耗时与接口调用量 | 每次运行有记录 |

### L2 数据与知识可信性（S1 起可测）

| 指标 | 口径 | 首期通过线 |
|---|---|---|
| 原文不可变 | 原始资料校验值抽查不变（资产清单 §2.2 全部文档） | 100% 不变 |
| 来源可定位率 | 知识卡 `source_ids` 可精确定位（路径+标题/段落/行号）的比例 | 100% |
| 缺失如实率 | 抽查卡片：无虚构补全（unknown/open_questions 使用正确） | 100% |
| 状态合规率 | `pending_validation` 知识未被表述为正式规则的比例 | 100% |
| 时间合规率 | 回放输入通过"当时可见"检查的比例 | 100% |
| 负面资产保留 | 已否决信号（中间带×离散度）、失败实验可检索 | 可检索 |
| 证据状态分布 | draft/pending/observing/active 分布统计 | 有分布即可，不设目标值（防凑数） |

### L3 分析质量（S2 起可测）

| 指标 | 口径 | 首期通过线 |
|---|---|---|
| 数值确定性 | 报告数值 100% 来自 facts 引用的确定性计算 | 100% |
| 引用真实性 | 引用 ID 真实存在且可定位（抽查） | 100% |
| 分栏完整性 | 事实/外部观点/个人经验/LLM 假设/实验结论分栏无混淆 | 每份报告 |
| 口径标注合规 | 盘中估计值标 `intraday_estimate`、探索口径数据标口径 | 100% |
| 弃权正确性 | 评测集中"应弃权"样本实际弃权的比例；"不应弃权"样本未误弃权的比例 | 评测集建立后定基线，首轮只记录不设线 |
| 冲突呈现 | 已知冲突对被报告呈现的比例（评测集） | 同上 |
| 结构稳定性 | 相同版本输入重复运行，输出结构一致（字段级 diff） | 结构一致，文案允许波动 |
| 切分合规（backtest） | 实验的 evaluation 区间在设计冻结前未被读取（日志审计）；切分点有版本 | 100% |
| 前视无污染（backtest） | 回放输入通过 as_of 校验；paperwalk 后期信息不回灌历史实验 | 100% |

### L3b 反馈闭环累积（paperwalk，S2 起累积，只记录不设线）

| 指标 | 口径 |
|---|---|
| 闭环完整率 | 有 DecisionLog 且有对应 PaperTradeRecord 的 paperwalk 运行比例 |
| 事后结果追加率 | PTR 在观察窗口到期后实际追加 outcome 的比例 |
| 案例沉淀率 | 定期复盘后进入候选案例卡的 PTR 比例 |
| 决策一致性 | 相同输入与版本下模拟决策方向一致的比例 |
| 复盘纪律 | 事后信息是否仅以追加方式写入（审计） |

> 该层衡量"实践是否在积累成可借鉴的知识"，是 RSI 数据前提的健康度，不评价盈亏对错。

### L4 投资效果（**S5 前不评价，仅做准备**）

| 指标 | 说明 |
|---|---|
| 样本外表现 | 仅在有候选策略（S5）后，用独立样本与模拟验证评价；backtest 的 evaluation 区间结果是其前期证据 |
| 相对基准增量 | 复杂系统 vs 简单基准（如无水位的无条件基准，参考 P3b 报告口径） |
| 决策一致性 | 相同输入与版本 → 一致的知识匹配与建议 |
| 行为改进 | 个人执行偏差趋势（数据源：paperwalk 的 PTR 积累；真实交割单仍缺） |

**红线**：任何层不得以短期盈利（含 paperwalk 模拟盈亏）代替上述评价；单笔盈亏不得触发规则变更。

## 2. 评测运行机制

| 机制 | 内容 | 阶段 |
|---|---|---|
| 校验器 | 数据质量、时间合规、schema、引用真实性检查（WP-B06-02），不合格阻断或标记 | S1–S2 |
| 任务评测集 | 覆盖正常、缺失、冲突、边界、弃权五类样本（WP-B06-03） | S2–S3 |
| 回放 | 严格 as_of 回放；不能回放则输出缺口清单 | S3 |
| 对照 | 检索/提示词/模型变更与固定 Champion 基线比较 | S3 起 |
| 错误分类 | 失败输出按类型归档，可检索 | S3 起 |

## 3. 与门禁的关系

- G0（本阶段）：只审核"任务可验收"——本方案是否覆盖四类评价且无相互替代；
- G1 用 L1/L2；G2 用 L1–L3；G3 用全部可测层 + 回放；L4 最早在 G5 出现；
- 各门禁通过条件以 Roadmap §4 为准，本方案提供度量手段，不修改门禁标准。

## 4. 已知限制（如实声明）

1. 弃权正确性、冲突呈现等指标依赖评测集，评测集在 S2–S3 才建立，当前无法给出基线值；
2. L4 行为改进原依赖真实交割单（仍缺）；paperwalk 的 PTR 积累可提供模拟口径替代数据源，但两者不可混用；
3. 本方案未定义投资层的具体回测口径——S5 前明确属于非目标；
4. L3b 只记录不设线，防止为凑指标而制造无意义交易。

## 1. 盘点结论摘要

- 已有**较丰富的大盘特色指标资产**（画像族 6 维 + 信号族 + 同步层 3 指标 + 行业资金流），与 Roadmap "已有部分大盘特色指标沉淀"的起点假设一致；
- 已有**相当份量的验证性文档**（regime 矩阵、相似胜率、P0 接口验收、蓄水池检验等），是 B2 知识卡改造的真实来源；
- **知识库为零起步**：全部经验目前以 Markdown 文档与代码注释存在，无卡片化、无状态机、无检索索引；
- **无交割单、无复盘记录、无案例库、无新闻管道、无决策日志**——对应卡片类型保持未启用；
- **工作区无 git 版本库**：现有程序与文档的版本追溯能力缺失，是当前最大治理风险。

## 3. 指标复现所需最小行情字段（B1 输入需求，S1 验证）

依据 D1/D6/D7 与 README 记载的口径整理，供 WP-B01-02/03 核对：

| 指标族 | 最小字段 | tushare 接口（据现有文档） | 频率/备注 |
|---|---|---|---|
| 温度/离散度/相关性 | 全市场个股日线：ts_code、trade_date、close/pct_chg、vol、amount；行业归属 | `daily`、行业分类（sw/ths） | 日频；盘中估计另走 akshare 新浪快照（单位股，需÷100） |

| 画像-估值 | 全市场 PE-TTM/PB、换手率 | `daily_basic`（历史段经 MySQL） | 日频 |
| 画像-杠杆 | rzye/rzmre/rzche（沪深北三所） | `margin` | 日频，当日可能不齐（已有护栏） |
| 画像-ETF净流入 | ETF 份额、单位净值（12 只宽基篮子） | `fund_share`、`fund_nav` | 份额 T+1 |

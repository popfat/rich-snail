## 硬约束（继承两份母文档）

1. 原始资料不可变；本项目只存只读引用；
2. 不虚构数据、案例、实验结果、审核结论；缺失标 `unknown`/`open_questions`；
3. 任何文件与 git 配置不写入密钥（凭证仅存于 `../.env`，进程内使用）；
4. 门禁不倒序豁免；预研成果不标记正式可用；
5. 不承诺买卖点与收益；paperwalk 为模拟，不接自动交易；
6. backtest 的 evaluation 区间在实验设计冻结前禁读。

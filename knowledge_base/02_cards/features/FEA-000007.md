# 行业资金状态标注与风险标签（rich_trend）

## 定义与业务含义
按透明规则为 90 个同花顺行业每日标注主状态（阶梯：修复观察/早期吸筹/持续吸筹/趋势确认 + 数据不足/观察/衰减/中性）与独立风险标签（口径分歧/龙头独撑/单日脉冲/量价背离/高位拥挤）；历史标注不回改。

> ⚠️ 本卡只登记既有项目的计算产物与口径（所有者 D8 决策），本项目不实现该指标。

## 计算公式与参数版本
- 实现 `rich_trend/scripts/build_annotations.py`；规则版本 v1.0（SRC-000014）；
- 数据底座：MySQL `market_history_data.rt_*`（金额 fact 表万元、mart 表亿元；基准 000300.SH）。

## 已知数据限制
- 行业资金流原生起点 2024-09-10；ths_member 只有当前成分 → 每日快照；广度/结构类指标自 2024-12-24 起可计算；
- 金额单位坑：`moneyflow_ind_ths` 原始为亿元（×10000 入库）；`moneyflow_ths` 为万元；`daily` amount 为千元。

## 候选决策角色
- regime/explain：状态与标签是结构健康标记；P3b 证据显示衰减/龙头独撑/单日脉冲**不预示显著负收益**（负面对照不成立），不可当看跌信号；
- risk：高位拥挤、高浮盈+拥挤有回撤预警证据（EXP-000005 R5：深回撤概率 +12pp）；
- D4 深套企稳信号（d4_signal）：观察工具，升级"已验证"前仅观察（HYP-000005）。

# rich_trend 行业资金状态机与证据阶梯

## 一句话命题
每个行业每个交易日恰好处于一个主状态，机会状态按证据强度构成阶梯：修复观察(0) → 早期吸筹(1) → 持续吸筹(2) → 趋势确认(3)；另有可叠加的独立风险标签；历史标注不回改。

## 原始依据与精确定位
- `rich_trend/docs/状态定义与迁移说明.md` §1（状态机）、§2（阶梯与判定条件表）、§3.5（D4 信号层）、§4（风险标签）。

## 操作化定义
- 阶梯判定条件：见原文 §2 表（透明规则，如早期吸筹=异常流入 F_Amt>0 且 RobustZ≥1.5 等）；
- 补充状态：数据不足/观察/衰减/中性；判定优先级：数据不足 → 趋势确认 → 持续吸筹 → 早期吸筹 → 修复观察 → 观察 → 衰减 → 中性；
- 独立风险标签（可叠加）：口径分歧、龙头独撑、单日脉冲、量价背离、高位拥挤；
- D4 深套企稳是独立于状态机的观察信号（d4_signal 列，20 日追踪窗，见 HYP-000005）。

## 不交易／不使用条件
数据不足不生成任何机会/强方向标签；路径分类（升级/延续/回落/衰减）属描述性统计，含前视成分，不可按触发日入场理解。
